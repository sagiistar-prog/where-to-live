# 在住房决策前查清依据

2026-09-18，本次在已收录的32个官方来源上增加10个独立文件，覆盖全国以及北京、上海、广州、深圳的部分住房事项。总计42个来源，不代表完整法规库。此次只扩展已有产品的买房成本核对和纠纷处理需求，没有新增城市或实时房源能力。

## 用户任务与资料选择

| 用户此刻需要做什么 | 新增依据 | 产品如何帮助 |
|---|---|---|
| 买房前留足税费 | 2024年第16号住房交易税收公告、住房贷款利息扣除问答 | 核对家庭范围、面积、申请资料；区分税前扣除和实际退税 |
| 看懂贷款合同 | 公积金贷款利率通知、北京新旧贷款调整公告、2024年第11号房贷定价公告 | 区分固定/浮动利率、重定价周期及新旧贷款，明确通知日期，不冒充银行报价 |
| 核实房屋和付款安排 | 2025年修正的不动产登记资料查询办法、北京存量房流程通知 | 查居住权、抵押、查封及资金托管条件，不暴露他人隐私或保证交易安全 |
| 准备处理押金或维修争议 | 民事证据规定、人民调解法、法律援助法 | 提示保留完整记录、了解自愿调解、核对援助资格，不预测裁判结果 |

原有32个来源继续覆盖租赁合同、公积金租房提取、备案、保租房、消防、燃气和噪声。完整链接及适用条件见[来源目录](../knowledge/sources.json)，下载自带的是[原创简短整理](../knowledge/reference-notes.json)。政府及法院全文仅由显式采集命令保存到本地，未提交第三方全文或生成的向量。

## 搜索之后仍需作出的判断

- 北京2016年通知写有强制存量房资金监管，但2018年第182号文件已取消强制要求。只将后者纳入当前新资料，不把两个版本作为同时有效的建议。
- 2019年契税问答仍能搜到90平方米门槛，本次采用明确写明替代旧文件的2024年第16号公告。未把搜索排名当时效证据。
- 不动产查询办法页面路径含2024，正文已列2025年修正并涵盖居住权。版本以正文为准，未知页面发布日期留空，不伪造精确日期。
- 公积金利率保留“2025年5月通知”标识。网页能够查到一份通知不代表利率实时有效，更不能推断具体用户获批利率。
- 个人银行操作公告只能证明该银行的流程，本次采用人民银行全国机制，不将银行的申请次数限制推广到全国。
- 3个首选页面遇到拒绝、重定向循环或TLS错误后，改用可正常读取的政府或法院同文页面。保留证书验证，最终42/42采集成功。

## 可复查的工程链路

公开目录 → Schema校验 → 正文/表格抽取 → 清洗与JSONL → 320字符切分及40字符重叠 → BGE模型真实推理 → 持久索引/pgvector → 地区与有效期过滤 → 关键词和向量分别召回 → RRF融合 → 原文出处及适用条件。

实际抽取179,065字符，生成662个片段，全部写入本地隔离PostgreSQL。模型为BAAI/bge-small-zh-v1.5、512维归一化向量，实际最大片段321 token；输入使用真实tokenizer检查，超限拒绝。token和position embedding由模型内部完成，检索使用最终句向量。模型并非自研。

JSON实现为BM25与余弦相似度；PostgreSQL实现为全文排名与pgvector余弦检索。两者都用RRF融合，但词法排名不同。本轮没有调整权重来追逐新增题的分数。

[采集与索引记录](evaluation/housing-decisions-corpus.json)包含每份资料的来源、抽取长度、采集时间、响应哈希及语料哈希。抽取标记用于发现明显缺页，不证明网页附件或全文完整性。

## 下载后如何使用

先运行仓库的`npm ci`和`npm run dev`，访问`/knowledge`即可查阅42条带出处的整理，无需账户、模型或数据库。需要全文混合检索时，按[知识库运行说明](../knowledge/README.md)安装Python依赖、执行采集和建索引命令。

服务启动后执行：

```sh
python knowledge/evaluate.py --index output/public-kb/index.json --cases knowledge/evaluation/decision-cases.json --output output/evaluation/decisions.json --cache-dir .cache/models --min-hit-rate 0.9 --max-false-evidence-rate 0
python knowledge/accept_service.py --index output/public-kb/index.json --base-url http://127.0.0.1:8782 --output output/evaluation/service.json
```

验收脚本要求正确的语料哈希、至少90%的来源命中、无边界题证据及无地区混入；失败返回非零退出码。输出路径必须全新。现有CI新增真实BGE服务的HTTP回归，使用原创虚构语料；上述42个官方来源的结果来自本次本地实际执行，不能混称为CI中的官方全文验收。

## 尚未证明的部分

此前设置`HOUSING_KB_URL`启动完整网页联调被自动审批拒绝，只有`blocked by policy`，未给出具体原因。本轮没有重试这一被拒操作；默认摘要网页与独立数据库服务分别通过，不能替代网页到向量数据库的完整端到端证据。生产客户数据库、律师审查、真实租客试用和业务效果均未验证。

下一次用户验收应测量：能否找到正确地区和时间范围的依据、是否理解需要补充的材料、是否把政策摘要误当作个案结论，以及完成任务的耗时。当前不填造用户成功率。
