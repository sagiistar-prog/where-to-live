## 更新流程

1. 将采集结果保存到全新目录，任何来源失败均不能输出完整语料文件。
2. 用 `knowledge/audit_snapshots.py` 比较前后JSONL。正文按清洗后哈希比较，原始响应哈希单列，避免把网页装饰变化直接等同于政策修改。
3. 按来源输出新增、移除、正文变化和元数据差异；需要人工重审的来源同时提醒重审下载自带的摘要。已知失效或尚未施行的资料即使正文不变也会被标记。
4. 核对变化、重建独立索引并通过检索评测后，再决定是否切换服务。审计工具不会自动更新服务或替用户批准新政策。

局限：比较对象是提取到的正文，无法证明缺失的附件或图片没有改变；它不主动发现新修法，也不会自动理解法律语义。哈希相同不是法律持续有效的证明。
