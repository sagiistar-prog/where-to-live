# 搬家之后，如何找到办理依据

住房选择会影响后续办证和公共服务。租客需要在签约前知道要向房东索取哪些材料，搬家后知道登记、申领和签注的区别。本轮增加北京、上海、广州的官方办事资料，并让直接询问“居住证”的用户能够进入检索。

## 来源选择

- 北京：[申领办理指南](https://www.beijing.gov.cn/fuwu/bmfw/bmzt/jzz/blzn/201806/t20180622_1857738.html)，页面更新日期2025-11-04。不同申领路径的材料不能混用；页面带归档标识，摘要明确提示办理前复核。
- 上海：[2025年修订解读](https://www.shanghai.gov.cn/wzjd/20251201/9115cdc996fa4fdfa577bb7ce1eaa5a2.html)。检索仍能找到2023年旧版，本轮选择新解读，不将旧版备案证明要求写成唯一途径。
- 广州：[电子居住证办事指南](https://zsj.gz.gov.cn/zmhd/cjwt/shbapp/content/post_10146719.html)。区分普通路径与绿色通道；不省略绿色通道须先登记的条件。
- 深圳：[公安办事问答](https://ga.sz.gov.cn/ZT/JZZ/)已通过网页阅读发现，但本机采集遇到TLS错误，兼容性探测随后返回403。本轮没有把搜索结果摘要当作完整采集，没有将该来源写入索引。既有5个深圳来源保留。

法规、官方解读、办事指南的作用不同。资料只用于寻找依据，不判断申请人必然符合条件。没有采集个人信息，也没有提交办证申请。

## 本轮数据

45个来源重新采集全部成功：全国17、北京11、上海5、广州7、深圳5。清洗后182,897字符，676个片段，每个片段最多320字符、相邻重叠40字符。完整JSONL保存在本地输出目录，原始采集和向量文件不提交Git。仓库附带45条原创摘要，直接启动网页即可查询。

FastEmbed实际调用BAAI/bge-small-zh-v1.5，生成676条512维归一化向量。验证了向量数量、维度、有限值和范数。模型处理token与position embedding，应用使用上下文句向量；真实tokenizer在推理前检查512-token上限。JSON服务采用BM25、余弦距离及RRF融合，数据库实现采用pgvector、PostgreSQL全文排名与RRF。两者词法算法不同，不混称为BM25。

[来源覆盖清单](knowledge-source-coverage.json)与[本轮语料记录](evaluation/housing-residency-corpus.json)记录来源、日期、哈希及模型。旧快照保留。32来源旧覆盖清单已更新，历史验收文档中的32或42仍表示当时的快照。

## 验证及取舍

[58题回归](evaluation/housing-residency-component.json)包括原52题及新增6题，均为作者标注的来源相关性测试，不是独立用户评估或法律准确率。

| 检索模式 | 有来源问题Top3命中 | 边界题错误输出证据 | 跨地区混入 |
| --- | --- | --- | --- |
| 关键词 | 50/50 | 0/8 | 0 |
| 向量 | 47/50 | 0/8 | 0 |
| 混合 | 49/50 | 0/8 | 0 |

不因加入向量就宣称优于关键词。这批题偏向官方用语，后续需要真实用户问法验证；未为提高分数修改原题或降低证据要求。

默认摘要搜索的视觉检查发现，居住证问题会因少量共有词展示噪声和不动产资料。本轮保留得分达到最高候选35%的结果，最多5条，减少低相关内容。这是可解释的排序启发式，不是置信度，不作用于全文混合检索。15项TypeScript测试覆盖既有住房任务、新办证任务、来源对应及地区边界。

[摘要排序对照](evaluation/housing-residency-summary.json)保持同一45条摘要、同一范围规则和58道题，只比较结果裁剪。修改前后均命中50/50道有来源题，8道边界题均无结果，平均来源精度从0.237升至0.648。标签可能未穷尽所有相关来源；这是已观察题集上的回归，不是独立泛化证据。

Impeccable审计评分15/20：无障碍3、性能4、响应式3、主题2、实现一致性3。主要后续项是部分链接及折叠控件未达到44像素触达高度（P2），以及本页颜色仍为与设计文件对应的硬编码值（P2）。没有以自动检测零违规宣称页面完全无障碍。

[浏览器验收](evaluation/housing-residency-ui.json)使用生产构建的默认摘要模式，在1440和390像素宽度完成三城查询、展开适用条件、核对官方链接。无横向溢出、浏览器异常或axe自动检测违规；不等于完整WCAG认证。Impeccable静态检测未发现匹配项。该页面保持蓝灰、留白、一个主操作，正文无中点分隔符。

## 复现

初始化命令见[知识库运行说明](../knowledge/README.md)。在完成完整采集和新索引构建后：

```powershell
python knowledge/evaluate.py --index output/public-kb/index.json --cases knowledge/evaluation/residency-cases.json --cache-dir .cache/models --output output/evaluation/residency.json --min-hit-rate 0.95 --max-false-evidence-rate 0
python -m unittest discover -s knowledge -v
npm test
npm run build
```

本地Python测试33项中30项通过，3项数据库测试需隔离数据库环境，由GitHub PostgreSQL工作流执行。当前资料不是全国完整政策库，未收录的附件及图解不计为已入库。网页到独立向量服务的完整联调仍未验收：此前启动动作被自动审批拒绝，仅返回`blocked by policy`，未给具体原因，本轮未重试该动作。没有真实租客参与或生产客户效果数据。
