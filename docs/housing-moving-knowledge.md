# 让搬家和每月账单有据可查

2026-09-18。资料库从45个官方来源扩至54个，默认网页附带54条原创整理，全文链路实际采集198,376个清洗后字符，生成735个片段和735条512维BGE向量。范围是全国通用规则及北上广深部分资料，不是全国完整政策库。

## 从用户任务补资料

| 用户任务 | 本轮补充 | 必须保留的条件 |
| --- | --- | --- |
| 搬家后维护办理信息 | 北京居住证地址变更、全国住房租金个税记录修改 | 北京指南有归档标志，向当前窗口核对；如实填报租期，不把扣除额当退税额 |
| 核对每月账单 | 全国水电气暖收费规则，北京、上海、广州水价 | 地区、供水企业、账户性质、计费周期不同；自来水价不必然等于含污水费的总账单 |
| 合租多人共同生活 | 上海一户多人口水电气阶梯政策 | 需要居住证明、人数条件及申请，五人合租不自动获批 |
| 遇到消防隐患 | 广州出租人、实际管理人、承租人责任及报告路径 | 集中出租门槛不可套用所有普通住宅，不替代现场安全检查 |

来源选择以是否帮助用户完成下一步为准。没有为扩大量而录入重复转载、失效指引或实时房价猜测。用户先选房屋地区，再提出一个问题，阅读简要整理，按需展开适用条件并打开官方原文。界面保持既有蓝灰、留白和单一主操作。

## 采集中的真实问题

初筛10个候选时，深圳2页在本机出现`SSL: BAD_ECPOINT`，未进入正式目录或摘要。保留[选择记录](evaluation/housing-moving-source-selection.json)，没有关闭证书校验或把搜索摘要当作正文。

广州2025年原通知的水价表是图片。文字抽取能获取范围与实施规则，却没有表内价格。原通知摘要明确这项缺失，再找到[发改委官方文字解读](https://fgw.gz.gov.cn/gkmlpt/content/10/10242/post_10242178.html)补齐价格依据。因此新增9个来源，最终54/54采集成功。未声称对原图完成OCR。

综合税务问答只收第一项住房租金内容；广州消防只收第十八条租赁房屋职责。新增`extract_section`目录契约，明确起止标记与节名。标记缺失、重复或逆序时采集失败，避免网页变化后混入无关章节。片段位置相对于清洗后的所选正文，`char_start`与`char_end`可准确还原片段；节名随片段保留。

与前45来源快照比较，9个新增、44个正文与元数据未变、1个仅原始响应变化，没有已知日期排除项。见[快照差异](evaluation/housing-moving-final-source-diff.json)。这只能验证本次内容差异，不能证明没有尚未发现的废止文件。

## 技术证据

流程沿用Trafilatura正文抽取、JSONL、320字符切分与40字符重叠、FastEmbed实际ONNX推理、BAAI/bge-small-zh-v1.5、BM25与余弦召回、RRF融合。地区和已知有效期在排名前过滤。开源架构取舍见[知识库设计比较](rag-design-comparison.md)。

[语料与模型记录](evaluation/housing-moving-corpus.json)保存文档哈希、语料哈希、模型标识和tokenizer哈希。735条向量均通过维度、有限值和归一化检查；735个片段均通过正文精确回读，最大321 token，未超过模型512 token限制。模型内部处理token与位置表示，检索使用上下文句向量。

本机初次构建发现住房目录模型缓存不完整，随后复用本地同一模型的完整文件完成推理；没有使用随机向量或旧索引冒充新语料。

## 运行与边界

默认网页：`npm ci`后`npm run dev`，打开`/knowledge`，无须模型、数据库或账号。全文重建和服务命令见[运行说明](../knowledge/README.md)。全文抓取结果和模型不打包进Git，首次构建需要网络。

```sh
python knowledge/evaluate.py --index output/public-kb/index.json --cases knowledge/evaluation/moving-cases.json --cache-dir .cache/models --output output/evaluation/moving.json --min-hit-rate 0.95 --max-false-evidence-rate 0
node --import tsx scripts/evaluate-knowledge-summary.ts knowledge/evaluation/moving-cases.json output/evaluation/summary.json 2026-09-18
python -m unittest discover -s knowledge -v
```

本轮完成本地新语料与默认网页验收，没有将54来源新索引写入生产数据库。此前网页连接独立向量服务的启动动作曾被自动审批拒绝，返回`blocked by policy`且未给具体原因，本轮未重试等价动作；完整网页到向量服务联调仍未验收。也没有真实租客参与或客户效果数据。下一步应招募租客，比较使用前后的账单遗漏项、找依据耗时和下一步行动完成率。
